카드 티어 표시 초안 (승인 전)

카드 24×29, 4배 확대. 티어은 카드 아래 가운데 "티어 판"으로 표시. 강화(몸통 모서리 고정 별)와 자리가 달라 겹쳐도 구분됨.

A안: 색 판 + 눈금 + 고티어 장식

티어 1~10. 판 색이 단계, 판 아래 눈금(점) 1~3개가 색 안의 단계를 구분. 6티어부터 윗변 모서리 장식, 9티어부터 윗변 금속선.

B안: 도트 숫자 판

판 안에 3×5 도트 숫자. 10 이상도 두 자리로 정확히 읽힘. 판 색은 같은 단계색.

계열 테두리·강화·미보유와 함께 (A안)

왼쪽부터: 기본(강철) 3 / 대검 A 파쇄 5 / 대검 B 검기 7 / 기본 + 강화(고정 별) 7 / 미보유 흐림 4
