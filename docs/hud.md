# HUD (docs/hud.md)

전투·섬 화면의 HUD 배치와 표시 규칙. 좌표는 내부 해상도 288×162 기준 (화면 구성은 docs/art.md 1장).
색은 palette.json global.ui, 숫자는 3×5 도트 글꼴(art.md 7장).

**원칙**: 전투 영역(세로 20~140)에는 고정 HUD를 두지 않는다. 몬스터와 예고 범위가 가려지면 안 된다.

## 2. 위쪽 (0~20, 가끔 보는 정보)

| 위치 | 요소 | 표시 규칙 |
|---|---|---|
| 왼쪽 위 | 파티원 프레임 (최대 3명, 세로로) | 플레이어 색 막대 + 얼굴 + 작은 HP 바. 쓰러지면 흐리게 + 빨강 X, 접속 끊김이면 흐리게 + 점 세 개 |
| 오른쪽 위 | 방 진행 | 점 5개 + 보스 아이콘. 지난 방 연두, 현재 방 금색, 남은 방 어두움 (구현 client/src/ui/hudRoom.ts, 데모 hudTop 값: x = 화면 폭 − 62부터 9px 간격 6×6, 보스 아이콘 +46. 보스 방에서는 점 모두 금색·아이콘 주황) |
| 위 가운데 (보스전) | 보스 이름 + 여러 줄 HP 바 | 한 줄 = 보스 최대 체력의 1/12. 남은 줄 수 "×N", 줄이 바뀔 때 색이 바뀜. 그로기 중엔 "Zz" 표시 (구현 ui/hudBoss.ts, 데모 hudTop(boss) 위치·크기: 패널 x = 가운데 − 62, 아이콘 8×8, 막대 82×5 + 윗줄 global.ui.bossHpLight. 줄 색: 첫 줄 주황(bossHp) ↔ 분홍(floors.1.monster.sporeFlower 램프), 다음 줄 색을 막대 뒤에. 이름은 한글 글꼴 추가 뒤 — 지금은 아이콘) |

- 파티원 프레임 구현: client/src/ui/hudParty.ts (온라인만, 나 제외 입장 순서). 위치·모양은 승인 데모 hudTop과 같음: 줄 y = 3 + 13i, 색 막대 2×11(x 3), 패널 40×11(x 5, global.ui.panel 70%), 얼굴 12×11(x 6, 쓰러지면 45%), HP 바 22×2(x 20, y+4), 빨강 X는 데모 픽셀
- 접속 끊김 점 세 개는 데모에 없어 얼굴 아래 (8·11·14, y+8)에 global.ui.textDim으로. 끊김 상태는 M3에서 서버가 보냄
- 플레이어 색 번호 = 서버 입장 순서 (아래 띠 얼굴·캐릭터 색도 같은 번호). 앞사람이 나가면 번호가 당겨진다 (M4 계정에서 고정 예정)

## 4. 텍스트 채팅

- 섬·던전 어디서나 **Enter**로 입력창 열기 → Enter 전송 / Esc 취소. 섬 배치 모드에서는 Enter가 "놓기"라 채팅 불가 (배치 모드를 나와서 사용)
- 입력창이 열려 있는 동안 캐릭터 조작 정지 (이동·공격 키는 글자로 입력됨). 던전에서 열면 캐릭터는 제자리 대기 — 몬스터는 계속 움직이므로 위험은 본인 책임
- 범위: 같은 방(Room)에 있는 사람만. 섬에서는 섬에 있는 주민, 던전에서는 파티원. 섬↔던전 사이는 전달하지 않음
- 표시
  - 말한 사람 머리 위 말풍선 3초 (한글 도트 글꼴, 최대 2줄, 넘치면 말줄임)
  - 화면 왼쪽 아래(아래 HUD 띠 바로 위) 대화 기록 최근 5줄, 새 메시지 후 6초 뒤 흐려짐. 입력창을 열면 다시 선명하게
  - 이름은 플레이어 색으로
- 전투 영역을 가리지 않도록 던전에서는 대화 기록을 최근 3줄, 반투명으로
- 길이 최대 60자. 저장하지 않음 (방이 끝나면 사라짐)
- 위로 스크롤로 지난 대화 보기, 숨기기 토글은 MVP 이후

## 6. 정산 화면

던전 종료 시 순서대로 등장:
1. 클리어 / 귀환 / 전멸 결과
2. 코인 (금고 적립분 별도 표시), 콤보 보너스
3. 재료
4. 숙련도 경험치 바 + 레벨업
5. 첫 처치 보상 (SP, 의상, 트로피)
- 파티원별 요약은 한 줄씩. 아무 키나 누르면 섬으로
- 구현 client/src/ui/resultPanel.ts: 가운데 패널(폭 160)에 0.35초마다 한 줄씩 (fx.json hud.resultStepSec). 결과(CLEAR! 금색 / RETURN 연두 / WIPE 위험색, 2배) → 코인 합계(+보너스% 또는 −잃은 코인) → "> 지갑 코인 · 금고(작은 상자 아이콘)" → 재료 → EXP 막대 + LV(올랐으면 LV UP! 깜빡임) → 파티원 줄(색 막대 + 얼굴 + 지갑 코인 + 재료)
- 한글 글꼴(갈무리)이 아직 없어 이름 대신 플레이어 색·얼굴로 구분 (글꼴 추가 때 이름). 3×5 글꼴에 N W - > 추가
- 섬(M4) 전까지는 아무 키 → 새 판으로 다시 접속. 첫 처치 보상(5번)은 M4

## 7. 글꼴

- 숫자·영문 짧은 표시: 3×5 도트 글꼴 (자체 제작)
- 한글: **갈무리(Galmuri)** — SIL OFL 1.1 비트맵 글꼴. 내부 해상도 기준 Galmuri9(고유 크기 12px: 기준선 위 11 + 아래 1)를 이름·알림에, 아주 작은 표시는 Galmuri7(10px: 9 + 1, 일부 한글만 지원 → 없는 글자는 '?')
- OFL 조건: 글꼴 파일을 함께 배포할 때 저작권·라이선스 고지를 포함 (게임 내 크레딧 화면 + 저장소의 라이선스 파일)
- 글꼴은 정수 배율로만 확대
- **캔버스 글자는 비트맵 그대로**: 브라우저 글꼴 렌더링(woff2·Phaser Text)은 어느 크기에서도 가장자리를 반투명하게 섞어 도트가 깨진다. 그래서 갈무리 배포본의 BDF를 `pnpm font-gen <갈무리 dist 폴더>`로 .bin(글자표 + 비트맵, 형식 client/src/ui/glyphFont.ts)으로 바꿔 두고, client/src/ui/koText.ts(`koText(scene, x, y, 글자, { color, size, outline, align })`)가 픽셀을 찍는다. 넣는 글자: 영문·숫자·기호, 한글 자모·음절 11,172자, 문장 부호 (tools/font-gen/bdf.ts RANGES)
- DOM 입력창(로그인·채팅·메모)만 Galmuri9.woff2 (입력은 브라우저 글꼴이 필요). 크기 = 12px × 정수 배율
- 파일: client/public/fonts/Galmuri9.bin·Galmuri7.bin·Galmuri9.woff2 (갈무리 2.40.3), 라이선스 전문 Galmuri-OFL.txt, 출처 기록 저장소 루트 CREDITS.md

## 9. 로그인 화면 (M4 4-3)

- 시작: 글꼴을 받은 뒤 세션이 있으면(`GET /api/me`) 섬으로, 없으면 로그인 화면. 개발 경로 `?room=N`·`?online=1`은 로그인 없이 던전
- 한글 입력기 때문에 **DOM 폼**을 게임 위에 겹친다 (client/src/ui/dom/). 모양은 도트 패널: 색 global.ui (panel·panelBorder·panelInner·barTrack·coin 버튼·bossHp 오류), 크기는 게임 정수 배율의 배수. 패널이 화면보다 크면 들어갈 때까지 배율을 한 단계씩 줄임
- 탭: 로그인 / 가입 (닉네임·비밀번호·확인·초대 코드 선택). 아래 "비밀번호를 잊었어요" → 닉네임·복구 코드·새 비밀번호
- 형식 검사는 서버와 같은 shared/src/auth.ts 스키마. 틀린 칸에 주황 테두리 + 문구 한 줄 (서버 오류 문구는 client/src/net/api.ts)
- 가입·복구 뒤 복구 코드 화면 (한 번만, 복사하기 / 적어 두었어요) → 섬
- 글자는 모두 textContent (innerHTML 금지). 비밀번호 관리자를 위해 autocomplete(username·current-password·new-password)
- 섬 씬은 4-5 전까지 임시 화면 (섬 이름·닉네임·지갑·금고·초대 코드, L 로그아웃)
