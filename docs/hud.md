# HUD (docs/hud.md)

전투·섬 화면의 HUD 배치와 표시 규칙. 좌표는 내부 해상도 288×162 기준 (화면 구성은 docs/art.md 1장).
색은 palette.json global.ui, 숫자는 3×5 도트 글꼴(art.md 7장).

**원칙**: 전투 영역(세로 20~140)에는 고정 HUD를 두지 않는다. 몬스터와 예고 범위가 가려지면 안 된다.

---

## 1. 아래 HUD 띠 (140~162, 가장 자주 보는 정보)

| 위치 (x) | 요소 | 표시 규칙 |
|---|---|---|
| 3~19 | 내 얼굴 | 캐릭터 스프라이트의 얼굴 부분 (현재 표정 반영: 피격·기쁨) |
| 23~75 | HP 바 (52×4), MP 바 (52×3), 숙련도 레벨 | 바는 위 절반 밝은색·아래 절반 어두운색. 줄어든 부분은 0.4초 동안 흰색으로 남았다 사라짐 |
| 86~186 | 슬롯 J U I O P (각 18×18, 간격 2) | J = 무기 아이콘. 키 글자는 왼쪽 위 |
| 192~210 | 필살기 L | 게이지가 차오르는 동안 아래에서 위로 채움, 100이면 금색 테두리 깜빡임 |
| 222~252 | 물약 Z, X | 남은 개수, 사용 쿨타임 중엔 어둡게 |
| 257~285 | 이번 판 코인·재료 | 획득 시 숫자가 한 번 튐 |

### 슬롯 상태
| 상태 | 표시 |
|---|---|
| 사용 가능 | 기본 |
| 쿨타임 | 위에서부터 어두운 덮개, 시간이 지날수록 위로 걷힘 |
| MP 부족 | 아이콘 회색 |
| 장착 안 됨 | 빈 슬롯 (흐린 잠금 표시) |
| 시전 중 | 테두리 금색 |
| 방금 사용 가능해짐 | 0.2초 흰 테두리 깜빡임 |

## 2. 위쪽 (0~20, 가끔 보는 정보)

| 위치 | 요소 | 표시 규칙 |
|---|---|---|
| 왼쪽 위 | 파티원 프레임 (최대 3명, 세로로) | 플레이어 색 막대 + 얼굴 + 작은 HP 바. 쓰러지면 흐리게 + 빨강 X, 접속 끊김이면 흐리게 + 점 세 개 |
| 오른쪽 위 | 방 진행 | 점 5개 + 보스 아이콘. 지난 방 연두, 현재 방 금색, 남은 방 어두움 |
| 위 가운데 (보스전) | 보스 이름 + 여러 줄 HP 바 | 한 줄 = 보스 최대 체력의 1/12. 남은 줄 수 "×N", 줄이 바뀔 때 색이 바뀜. 그로기 중엔 "Zz" 표시 |

## 3. 전투 화면 안 (월드에 붙는 표시)

| 요소 | 표시 |
|---|---|
| 동료 표시 | 머리 위 플레이어 색 작은 삼각형 + 이름(한글 도트 글꼴, 작게) |
| 이모트 | 머리 위 말풍선 1.5초 |
| 부활 게이지 | 쓰러진 동료 위 막대 (연두) |
| 상호작용 | 대상 위 [E] (나에게만) |
| 화면 밖 동료 | 화면 가장자리 플레이어 색 화살표 |
| 데미지 숫자·콤보 | art.md 7장. 콤보는 오른쪽 가운데 |
| 솔로 부활의 깃털 | 아래 HUD 띠 얼굴 옆 작은 깃털 아이콘 (사용하면 사라짐) |

## 4. 텍스트 채팅

- 섬·던전 어디서나 **Enter**로 입력창 열기 → Enter 전송 / Esc 취소. 섬 배치 모드에서는 Enter가 "놓기"라 채팅 불가 (배치 모드를 나와서 사용)
- 입력창이 열려 있는 동안 캐릭터 조작 정지 (이동·공격 키는 글자로 입력됨). 던전에서 열면 캐릭터는 제자리 대기 — 몬스터는 계속 움직이므로 위험은 본인 책임
- 범위: 같은 방(Room)에 있는 사람만. 섬에서는 섬에 있는 주민, 던전에서는 파티원. 섬↔던전 사이는 전달하지 않음
- 표시
  - 말한 사람 머리 위 말풍선 3초 (한글 도트 글꼴, 최대 2줄, 넘치면 말줄임)
  - 화면 왼쪽 아래(아래 HUD 띠 바로 위) 대화 기록 최근 5줄, 새 메시지 후 6초 뒤 흐려짐. 입력창을 열면 다시 선명하게
  - 이름은 플레이어 색으로
- 전투 영역을 가리지 않도록 던전에서는 대화 기록을 최근 3줄, 반투명으로
- 길이 최대 60자. 저장하지 않음 (방이 끝나면 사라짐)
- 위로 스크롤로 지난 대화 보기, 숨기기 토글은 MVP 이후

## 5. 알림

| 상황 | 표시 |
|---|---|
| 방 클리어 | 화면 가운데 가로 띠 + "CLEAR!" 0.8초, 출구 문 빛남 |

| 레벨업 | 내 캐릭터 위 빛 기둥 + "LV UP" |

## 6. 정산 화면

던전 종료 시 순서대로 등장:
1. 클리어 / 귀환 / 전멸 결과
2. 코인 (금고 적립분 별도 표시), 콤보 보너스
3. 재료
4. 숙련도 경험치 바 + 레벨업
5. 첫 처치 보상 (SP, 의상, 트로피)
- 파티원별 요약은 한 줄씩. 아무 키나 누르면 섬으로

## 7. 글꼴

- 숫자·영문 짧은 표시: 3×5 도트 글꼴 (자체 제작)
- 한글: **갈무리(Galmuri)** — SIL OFL 1.1 비트맵 글꼴. 내부 해상도 기준 Galmuri9(10px)를 이름·알림에, 아주 작은 표시는 Galmuri7(8px, 일부 한글만 지원하므로 사용 글자 확인)
- OFL 조건: 글꼴 파일을 함께 배포할 때 저작권·라이선스 고지를 포함 (게임 내 크레딧 화면 + 저장소의 라이선스 파일)
- 글꼴은 정수 배율로만 확대

## 8. 섬 HUD

### 조작
- 섬에서는 키보드와 **마우스를 함께 지원** (배치·패널 조작). 던전은 키보드 전용

### 기본 화면
| 위치 | 요소 |
|---|---|
| 아래 띠 왼쪽 | 내 얼굴, 이름, 레벨 |
| 아래 띠 가운데 | 단축 버튼 B(배치 모드), I(가방), M(게시판) |
| 아래 띠 오른쪽 | 지갑(동전 아이콘), 공동 금고(상자 아이콘) |
| 오른쪽 위 | 주민 목록: 플레이어 색 막대 + 얼굴 + 상태 (섬 = 연두 점, 탐험 중 = 검 아이콘 + 층 숫자, 오프라인 = 흐린 얼굴 + 점 세 개) |
| 월드 | 주민 이름·이모트, 상호작용 대상 위 [E] |

### 배치 모드
- 아래 띠가 가방 속 장식 목록(아이콘 + 개수)으로 바뀌고, 선택한 장식은 금색 테두리
- 오른쪽에 조작 키 안내: 방향키·마우스 이동, R 회전, Enter·클릭 놓기, X 치우기, Esc 나가기
- 장식에 커서를 올리면 이름과 놓은 사람을 작은 말풍선으로
- 표시 규칙은 art.md 6장 "배치 모드 표시"

### 패널 (화면 가운데 도트 패널)
| 패널 | 내용 |
|---|---|
| 잡화점 | 탭(물약 / 장식 / 의상 — 의상 탭은 MVP 이후), 목록(아이콘·이름·가격), 구매 수량, 지갑 잔액 |
| 우물 출발 대기 | 층 선택(해금된 층만), 대기 중인 주민 얼굴, 출발 버튼(대기 시작자만), 카운트다운 |
| 게시판 | 활동 기록 목록, 메모 쓰기(1줄) |
| 가방 | 장식·재료·물약·의상 탭 |
- 패널이 열려 있으면 캐릭터 이동 정지. Esc 또는 바깥 클릭으로 닫기
