# 로드맵 (docs/roadmap.md)

MVP 범위, 마일스톤별 목표·읽을 문서·완료 기준, 세션 단위 작업 목록. 진행 체크는 CLAUDE.md "개발 순서".

---

## 1. MVP 범위

### 포함
- 계정: 가입·로그인·로그아웃, Argon2id, 쿠키 세션, 복구 코드, 요청 제한, 입력 검증
- 섬: 생성·초대 코드 참가, 고정 시설 5종, 장식 10종 + 분수, 배치·회전·이동·치우기, 잡화점(물약·장식), 게시판 기록, 우물 출발 대기
- 캐릭터: 16px 기본 캐릭터, 머리 모양 3종, 초보 모험가 의상, 표정 3종
- 무기: 대검(평타·대시 공격·기본 스킬 2) + 스태프(같은 구성)
- 조작·전투: 걷기·달리기·백스텝, 경직·다운·바운드, HP·MP, 물약 2종, 기절·부활, 귀환, 정산
- 던전: 버섯 숲 1층 (방 5개 + 보스), 몬스터 5종 전부, 재료 1종(버섯)
- 솔로 규칙: 공격 토큰, 부활의 깃털, 개인 콤보
- 성장: 숙련도 경험치·레벨 (공격력·HP 반영)
- 소통: 텍스트 채팅(섬·던전), 이모트 1~4, 게시판 메모
- 소리: 합성 효과음 (audio.md 3장 목록), 합성 BGM 3곡 (섬·1층·1층 보스, 확정), 볼륨 설정
- 운영: HTTPS·WSS, 백업, 관리자 명령줄 도구

### 제외 (MVP 이후)
- 2층 이상, 주먹·쌍검, 스킬트리 UI·계열 스킬·변형, 필살기
- 폭탄 버섯 등 환경 기믹, 층 해금 건물·연마, 공방 제작, 낚시
- 의상 판매·장착(마법사·도적·기사), 무기 외형(제작·보스 드롭·색 변형), 개인 집, 섬 방문·확장
- 계정 삭제 화면, 소셜 로그인, 모바일·게임패드, Steam, 2층 이후 BGM

## 2. 마일스톤

|---|---|---|---|

## 3. 작업 단위 (한 세션 = 한 줄)

각 줄을 끝내면 확인 방법을 실행하고 커밋한다. 다음 마일스톤의 작업 단위는 그 마일스톤을 시작할 때 이 표에 추가한다.

### M0
| # | 작업 | 확인 |
|---|---|---|
| 0-1 | pnpm 워크스페이스 뼈대 (client: Vite + Phaser + TS, server: Colyseus 빈 방, shared), tsconfig 경로, vitest | `pnpm dev`로 빈 288×162 화면이 정수 배율로 뜸, `pnpm test` 통과 |
| 0-2 | palette.json 로더 + tools/palette-check | 규칙 위반 0건 |
| 0-3 | 스프라이트 합성기 (마스크 → 레이어 → 자동 음영·외곽선 → 텍스처 캐시) | 기본 세트 4종 재질 격자 스냅샷 테스트 |
| 0-4 | tools/sprite-preview (의상·포즈·표정·몬스터 프레임 전환) | docs/refs/approved 캡처와 눈으로 비교 → 승인 |
| 0-5 | 던전 테스트 씬: 바닥·벽, 벨트스크롤 투영, 걷기, 통통버섯 배치 | 화면 구성이 art.md 1장과 같음 |

| 0-7 | tools/motion-preview (슬로우·프레임 넘기기·값 조정 → JSON 복사) | M0 체크 포인트(art.md 10장) 통과 → 승인 |
