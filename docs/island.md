# 섬 (docs/island.md)

섬의 공간, 시설, 장식, 건물, 상점 가격, 입장 흐름의 기준 문서.
정산 분배는 CLAUDE.md 핵심 게임 규칙, 전투·성장 수치는 docs/balance.md, 의상 외형은 docs/art.md.

---

## 1. 섬의 역할

- 던전이 긴장이라면 섬은 휴식. 전투 없음, 시간 제한 없음
- 판과 판 사이의 거점: 준비(무기·스킬·물약) → 출발 → 정산 → 꾸미기
- 함께 쌓은 기록: 장식에는 놓은 사람이, 트로피에는 함께 잡은 보스가 남는다
- 섬 꾸미기는 전투력과 거의 무관. 건물 보너스는 작게 (상한은 balance.md)

## 2. 공간

### 격자
- 40×30 격자. 1칸 = 1타일. 실제 칸 위치(시설·길·가장자리 나무·입장 자리)는 shared/data/island.json (data.md 8장)
- 섬 앞쪽 3줄은 모래·흙 절벽·물 (디오라마 단면, art.md 6장), 옆·뒤 가장자리는 두세 줄로 겹친 숲. 걷는 영역 36×25
- 들어오는 자리 (island.json spawn): 접속하면 남쪽 흙길 끝 **선착장**(배경 사물, 묶어 둔 작은 배), 던전에서 돌아오면 **우물 앞**(게시판 아래 흙길, 이름표가 게시판을 가리지 않게 한 줄 아래). 서버가 던전에서 나온 시각을 기억해 returnWindowSec(120초) 안에 들어오면 우물 앞, 그 밖(새로 접속·다시 접속)은 선착장 (server/src/systems/islandBus.ts)
- 섬 모양은 고정: 가장자리는 모래사장과 물 (배치 불가)
- 배치 가능 영역 약 30×22

### 시설 (섬 생성 시 자동 배치, 우물 빼고 옮길 수 있음)
| 시설 | 크기 | 처음 위치 | 기능 |
|---|---|---|---|
| 우물 | 3×3 | 중앙 | 던전 입구, 층 선택, 파티 대기 |
| 잡화점 | 3×2 | 우물 동쪽 | 물약·기본 장식 구매 |
| 무기 거치대 | 2×1 | 우물 서쪽 | 스킬트리, 슬롯 장착 (MVP 이후). MVP의 무기 교체는 우물 패널에서 (6장) |
| 게시판 | 1×1 | 우물 남쪽 | 활동 기록, 정산 기록, 메모 |
| 공용 창고 | 2×2 | 우물 북쪽 | 공동 금고로 산 장식·보스 트로피 보관 |

### 시설 옮기기
- 잡화점·공용 창고·게시판·무기 거치대는 섬 주민 누구나 배치 모드에서 옮긴다 (시설 위에서 Enter·클릭 = 들기 → 다시 Enter·클릭 = 놓기, Esc 취소). 우물은 던전 입구·복귀 자리라 중앙에 고정
- 회전·치우기 없음. 옮긴 위치는 섬마다 DB(island_facilities), 옮긴 적 없는 시설은 island.json 기본 칸
- 놓을 수 있는 자리: 장식과 같은 규칙(놓는 영역 안, 다른 시설·장식과 겹치지 않음, 우물 주변·다른 시설 입구·들어오는 자리 줄 피함, 사람 위 안 됨) + 새 입구(앞 줄 1칸)도 놓는 영역 안이고 장식·다른 시설이 없어야 함
- 흙길은 바닥 무늬라 처음 자리에 그대로 (새 길은 돌길 장식으로). 게시판에 "잡화점 옮김"으로 기록
- 규칙 코드 shared/src/island/placement.ts canMoveFacility, 처리 server/src/systems/islandPlacement.ts

### 건물 부지
- 층 해금 건물(4장)은 배치 가능 영역 어디든 지을 수 있음 (크기만큼 빈칸 필요)
- 지은 뒤 이동 가능, 철거 불가

### 개인 집 (MVP 이후)
- 주민마다 2×2 집 1채. 이동·외형 변경은 주인만 가능 (섬에서 유일한 개인 공간)

## 3. 장식

### 구하는 방법
| 방법 | 내용 |
|---|---|
| 잡화점 구매 | 기본 장식. 개인 지갑 |
| 공용 구매 | 대형 장식. 공동 금고 → 공용 창고로 |
| 공방 제작 | 층 재료 + 코인 (해당 건물 필요, MVP 이후) |
| 보스 트로피 | 보스 첫 처치 시 드롭 → 공용 창고 |

### 배치 규칙
- 섬 주민 누구나 놓기·옮기기·치우기·회전 가능 (같은 칸 동시 요청 처리는 CLAUDE.md 방 구조). 시설 옮기기는 2장
- 치운 장식은 **원래 놓은 사람**(placed_by) 인벤토리로 반환. 공동 금고로 산 것은 공용 창고로
- 회전 4방향 (90° 단위)
- 크기: 1×1 / 2×1 / 2×2 / 3×3
- 장식 위로 걸어 다닐 수 있는지는 장식마다 지정 (`walkable`)
- 우물 주변 1칸, 시설 입구 1칸(옮긴 시설은 새 자리 기준)은 비워둬야 함 (동선 보장). 들어오는 자리 줄(우물 앞 4칸)도 비움 (들어오다 갇히지 않게)
- 걸을 수 없는 장식은 주민이 서 있는 칸에 놓을 수 없음 (갇히지 않게)
- 꽃밭은 회전하면 꽃 색이 바뀜 (분홍·노랑 ↔ 하늘·흰색), 돌길은 그림이 아니라 바닥 무늬 (이웃과 이어짐)
- 장식 데이터(크기·가격·walkable·구매처): shared/data/items.json (data.md 9장), 규칙 코드 shared/src/island/placement.ts

### MVP 장식 (개인 지갑, 잡화점)
| 장식 | 크기 | 가격 | walkable |
|---|---|---|---|
| 꽃밭 | 1×1 | 40 | O |
| 돌길 | 1×1 | 30 | O |
| 울타리 | 1×1 | 30 | X |
| 화분 | 1×1 | 50 | X |
| 깃발 | 1×1 | 80 | X |
| 우체통 | 1×1 | 100 | X |
| 나무 | 1×1 | 120 | X |
| 벤치 | 2×1 | 150 | X |
| 가로등 | 1×1 | 180 | X |
| 모닥불 | 1×1 | 200 | X |

### MVP 공용 장식 (공동 금고)
| 장식 | 크기 | 가격 |
|---|---|---|
| 분수 | 3×3 | 1500 |

- 가격 감각: 한 판 수익 약 350코인(1인, balance.md 7장) → 매 판 작은 장식 1~3개. 분수는 혼자 금고만으로 약 14판, 4명이면 약 4판
- 장식 판매(되팔기) 없음

## 4. 층 해금 건물

- 해당 층 보스를 섬 주민 누구든 한 번 잡으면 건설 가능
- 비용: 공동 금고 코인 + 층 재료 (재료는 주민 누구의 인벤토리에서든 기부)
- 효과는 섬 주민 전원에게 적용

| 건물 | 크기 | 해금 | 비용 | 효과 |
|---|---|---|---|---|
| 물약 공방 | 3×2 | 1층 보스 | 2000 + 버섯 20 | 물약 반입 한도 각 +1. 버섯으로 물약 제작 (HP 물약 = 버섯 2) |
| 대장간 | 3×3 | 2층 보스 | 4000 + 수정 25 | 무기 연마 1~3단계 (단계당 ATK +2%, 단계마다 비용). 무기 외형 제작 |
| 연못·낚시터 | 4×3 | 3층 보스 | 5000 + 진주 25 | 낚시 미니게임 (물고기 → 코인·한정 장식). 비전투 콘텐츠 |
| 용광로 | 3×3 | 4층 보스 | 7000 + 흑요석 30 | 무기 연마 4~5단계 해금. 조명 장식 제작 |
| 유적 전시관 | 4×4 | 5층 보스 | 9000 + 고대 파편 30 | 보스 트로피 전시대, 몬스터 도감 |

### 무기 연마 (대장간·용광로)
| 단계 | 비용 (공동 금고) | 누적 ATK |
|---|---|---|
| 1 | 1000 + 수정 10 | +2% |
| 2 | 2000 + 수정 20 | +4% |
| 3 | 3500 + 수정 30 | +6% |
| 4 | 5000 + 흑요석 20 | +8% |
| 5 | 7000 + 흑요석 30 | +10% |

- 무기 종류 구분 없이 섬 전체 적용 (상한 +10%, balance.md)
- 연마는 "같이 모아서 같이 강해진다"는 공동 목표 역할

## 5. 상점 (잡화점)

| 품목 | 가격 | 비고 |
|---|---|---|
| HP 물약 | 15 | 효과는 balance.md |
| MP 물약 | 10 | |
| 기본 장식 | 3장 표 | |
| 의상 (모자·상의·하의·망토) | 150~400 | 외형 전용, 매주 일부 품목 교체 (MVP 이후) |
| 무기 외형 색 변형 | 200~500 | 기본·제작 외형의 색만 바꾼 버전, 매주 일부 품목 교체 (MVP 이후) |

- 개인 지갑으로 구매. 물약은 개인 인벤토리, 던전 입장 시 한도까지 자동 지참
- 공용 장식(분수 등, items.json source treasury)은 같은 잡화점 장식 탭에 '(금고)'로 있고, **주민 누구나** 확인 한 번("금고에서 N 씁니다") 뒤 공동 금고로 산다 → 공용 창고. 게시판에 '금고로 삼'으로 남는다
- 가격·이름: shared/data/items.json (decorations·consumables)
- 의상 획득처: 잡화점 구매, 각 층 보스 첫 처치 시 그 층 테마 의상 1벌 (외형은 art.md)

### 무기 외형 (외형 전용, 능력치 없음)
| 경로 | 내용 |
|---|---|
| 대장간 제작 (주된 경로) | 층마다 그 층 테마로 무기 4종 외형 1개씩. 비용 = 층 재료 + 코인 (개인 지갑). 대장간 건설 후 이용 |
| 보스 희귀 드롭 (자랑거리) | 층마다 보스 전용 외형 1개. 보스 처치 시 개인별 5% 판정, **내가 쓰던 무기 종류**로 드롭. 그 보스를 20번 잡도록 안 나오면 다음 처치에 확정(천장). 휘두를 때 스미어 색이 다름 |
| 잡화점 색 변형 | 기본·제작 외형의 색만 바꾼 버전 (가격은 위 표) |

- 무기 종류마다 따로 장착 (대검 외형을 바꿔도 스태프는 그대로). 장착은 무기 거치대에서
- 거래·되팔기 없음
- 제작 비용(1층 기준 초안): 버섯 10 + 300코인. 층마다 재료·코인 ×1.5

## 6. 입장 흐름

1. 우물에 상호작용 → 층 선택 (해금된 층만)
2. **출발 대기**: 우물 주변에 대기 표시. 다른 주민이 우물에 상호작용하면 합류
3. 대기 시작자가 "출발" → 10초 카운트다운 (그 사이 합류 가능, 최대 4명)
4. 솔로는 "출발" 즉시 입장
5. DungeonRoom 생성 → 파티 전원 이동. 출발한 사람은 그 자리에서 우물로 뛰어들고(효과음 wellJump) 화면이 어두워진 뒤 던전으로. 섬에 남은 주민 화면에도 뛰어드는 모습이 보인다 (상태가 dungeon:<층>으로 바뀌며 나간 주민). 섬에는 접속 중 표시만 남음
6. 던전 종료 → 정산 화면 (코인, 재료, 경험치, 금고 적립, 콤보 보너스) → 섬 우물 앞으로 복귀 (returnWindowSec 안에 들어올 때. 늦게 들어오거나 다시 접속하면 선착장, 2장). 우물 앞으로 들어오면 우물에서 튀어나와 착지한다 (서버 Resident.wellAt, 들어온 지 fx.json wellHop.popWindowSec 안에 처음 보일 때만. 그동안 본인은 조작 멈춤)

- 연출 구현: client/src/stage/wellHops.ts (주민별 뛰어들기·튀어나오기), 모양 client/src/fx/wellHop.ts, 값 fx.json wellHop (art.md 0장)

- 던전 중인 주민은 섬 화면에서 "탐험 중 (2층)" 같은 상태 표시
- 구현 (4-8): 우물 앞 E → 합류 + 우물 패널 (stage/islandPanels.ts). 카운트다운·최대 인원·층은 island.json well, 서버 server/src/systems/islandWell.ts. 대기 시작자가 빠지면 다음 사람이 이어받음
- 무기 (MVP 보충 ST-4): 우물 패널의 무기 버튼으로 대검 ↔ 스태프. users.weapon에 저장, 출발 때 파티 정보로 던전에 전달, 정산은 그 무기 숙련도(weapon_mastery)로. 섬 HUD LV = 고른 무기의 숙련도. 카운트다운 중인 대기자는 못 바꿈
- 던전에 가져가는 물약: 가방에서 한도(player.json potions.*.carry)까지. 가방에서는 정산 때 쓴 만큼만 빠짐
- 정산 결과는 게시판 기록으로 남음

## 7. 섬 주민

- 섬 하나당 주민 최대 10명 (shared AUTH.islandResidents, 섬 방 접속도 10명). 던전 파티는 따로 최대 4명 (5장 우물). 1인 1섬
- 가입하면 섬 없이 시작 → **섬 고르기 화면**: 모든 섬 목록(섬 이름·주인 닉네임·주민 N/10, 꽉 찬 섬은 흐리게·신청 불가)에서 **입장 신청**, 또는 **새 섬 만들기**("닉네임의 섬", 한 번 더 확인). MVP: 섬 옮기기·떠나기 없음
- 섬 주인 = 섬을 만든 사람 (islands.owner_id). 초대 코드 시절에 만든 섬은 가장 먼저 가입한 주민 (마이그레이션 0006)
- 입장 신청: 섬 없는 계정당 하나 (다른 섬에 신청하면 바뀜, 취소 가능). 신청자는 "허용 기다리는 중" 화면에서 3초마다 확인하다가 허용되면 바로 그 섬으로, 거절되면 한 번 알리고 목록으로
- 주인이 섬에 있으면 신청이 올 때 화면 위 알림 "OO님이 입장을 신청했습니다 (게시판 주민 탭)". 게시판 주민 탭에서 신청 줄을 골라 거절·허용 (주인만). 허용은 자리를 다시 확인하고 한 트랜잭션으로 주민이 됨, 활동 기록 "섬에 들어옴"
- 플레이어 색(스카프) 4색은 섬에서는 가입 순서로 돌려 써서 겹칠 수 있고, 우물 출발 때 파티 순서대로 다시 정해 파티 안에서는 겹치지 않음
- 주인 계정이 정지되면 그 섬은 신청을 허용할 사람이 없다 (MVP 범위 밖)
- 가입 선물: 꽃밭 2·울타리 4·화분 1 (items.json starter, 처음부터 꾸며 볼 수 있게)
- 섬 기본 장식: 새 섬을 만들 때 우물·게시판 둘레 꽃밭 4, 화분 2, 벤치 1, 길가 가로등 2, 선착장 앞 깃발 1을 공용 장식으로 놓아 둔다 (island.json starterDecor, 놓은 사람 없음). 옮기고 치울 수 있고 치우면 공용 창고로. 신청으로 들어온 주민은 더 놓지 않음
- 섬을 떠나면: 본인이 개인 지갑으로 산 장식은 본인 인벤토리로 회수, 공용 장식·건물·트로피는 섬에 남음
