# 섬 (docs/island.md)

섬의 공간, 시설, 장식, 건물, 상점 가격, 입장 흐름의 기준 문서.
정산 분배는 CLAUDE.md 핵심 게임 규칙, 전투·성장 수치는 docs/balance.md, 의상 외형은 docs/art.md.

---

## 1. 섬의 역할

- 던전이 긴장이라면 섬은 휴식. 전투 없음, 시간 제한 없음
- 판과 판 사이의 거점: 준비(무기·스킬·물약) → 출발 → 정산 → 꾸미기
- 함께 쌓은 기록: 장식에는 놓은 사람이, 트로피에는 함께 잡은 보스가 남는다
- 섬 꾸미기는 전투력과 거의 무관. 건물 보너스는 작게 (상한은 balance.md)

---

## 2. 공간

### 격자
- 40×30 격자. 1칸 = 1타일
- 섬 모양은 고정: 가장자리는 모래사장과 물 (배치 불가)
- 배치 가능 영역 약 30×22

### 고정 시설 (이동 불가, 섬 생성 시 자동 배치)
| 시설 | 크기 | 위치 | 기능 |
|---|---|---|---|
| 우물 | 3×3 | 중앙 | 던전 입구, 층 선택, 파티 대기 |
| 잡화점 | 3×2 | 우물 동쪽 | 물약·기본 장식 구매 |
| 무기 거치대 | 2×1 | 우물 서쪽 | 무기 교체, 스킬트리, 슬롯 장착 |
| 게시판 | 1×1 | 우물 남쪽 | 활동 기록, 정산 기록, 메모 |
| 공용 창고 | 2×2 | 우물 북쪽 | 공동 금고로 산 장식·보스 트로피 보관 |

### 건물 부지
- 층 해금 건물(4장)은 배치 가능 영역 어디든 지을 수 있음 (크기만큼 빈칸 필요)
- 지은 뒤 이동 가능, 철거 불가

### 개인 집 (MVP 이후)
- 주민마다 2×2 집 1채. 이동·외형 변경은 주인만 가능 (섬에서 유일한 개인 공간)

## 3. 장식

### 구하는 방법
| 방법 | 내용 |
|---|---|
| 잡화점 구매 | 기본 장식. 개인 지갑 |
| 공용 구매 | 대형 장식. 공동 금고 → 공용 창고로 |
| 공방 제작 | 층 재료 + 코인 (해당 건물 필요, MVP 이후) |
| 보스 트로피 | 보스 첫 처치 시 드롭 → 공용 창고 |

### 배치 규칙
- 섬 주민 누구나 놓기·옮기기·치우기·회전 가능 (같은 칸 동시 요청 처리는 CLAUDE.md 방 구조)
- 치운 장식은 **원래 놓은 사람**(placed_by) 인벤토리로 반환. 공동 금고로 산 것은 공용 창고로
- 회전 4방향 (90° 단위)
- 크기: 1×1 / 2×1 / 2×2 / 3×3
- 장식 위로 걸어 다닐 수 있는지는 장식마다 지정 (`walkable`)
- 우물 주변 1칸, 고정 시설 입구 1칸은 비워둬야 함 (동선 보장)

### MVP 장식 (개인 지갑, 잡화점)
| 장식 | 크기 | 가격 | walkable |
|---|---|---|---|
| 꽃밭 | 1×1 | 40 | O |
| 돌길 | 1×1 | 30 | O |
| 울타리 | 1×1 | 30 | X |
| 화분 | 1×1 | 50 | X |
| 깃발 | 1×1 | 80 | X |
| 우체통 | 1×1 | 100 | X |
| 나무 | 1×1 | 120 | X |
| 벤치 | 2×1 | 150 | X |
| 가로등 | 1×1 | 180 | X |
| 모닥불 | 1×1 | 200 | X |

### MVP 공용 장식 (공동 금고)
| 장식 | 크기 | 가격 |
|---|---|---|
| 분수 | 3×3 | 1500 |

- 가격 감각: 한 판 수익 약 350코인(1인, balance.md 7장) → 매 판 작은 장식 1~3개. 분수는 혼자 금고만으로 약 14판, 4명이면 약 4판
- 장식 판매(되팔기) 없음

## 4. 층 해금 건물

- 해당 층 보스를 섬 주민 누구든 한 번 잡으면 건설 가능
- 비용: 공동 금고 코인 + 층 재료 (재료는 주민 누구의 인벤토리에서든 기부)
- 효과는 섬 주민 전원에게 적용

| 건물 | 크기 | 해금 | 비용 | 효과 |
|---|---|---|---|---|
| 물약 공방 | 3×2 | 1층 보스 | 2000 + 버섯 20 | 물약 반입 한도 각 +1. 버섯으로 물약 제작 (HP 물약 = 버섯 2) |
| 대장간 | 3×3 | 2층 보스 | 4000 + 수정 25 | 무기 연마 1~3단계 (단계당 ATK +2%, 단계마다 비용). 무기 외형 제작 |
| 연못·낚시터 | 4×3 | 3층 보스 | 5000 + 진주 25 | 낚시 미니게임 (물고기 → 코인·한정 장식). 비전투 콘텐츠 |
| 용광로 | 3×3 | 4층 보스 | 7000 + 흑요석 30 | 무기 연마 4~5단계 해금. 조명 장식 제작 |
| 유적 전시관 | 4×4 | 5층 보스 | 9000 + 고대 파편 30 | 보스 트로피 전시대, 몬스터 도감 |

### 무기 연마 (대장간·용광로)
| 단계 | 비용 (공동 금고) | 누적 ATK |
|---|---|---|
| 1 | 1000 + 수정 10 | +2% |
| 2 | 2000 + 수정 20 | +4% |
| 3 | 3500 + 수정 30 | +6% |
| 4 | 5000 + 흑요석 20 | +8% |
| 5 | 7000 + 흑요석 30 | +10% |

- 무기 종류 구분 없이 섬 전체 적용 (상한 +10%, balance.md)
- 연마는 "같이 모아서 같이 강해진다"는 공동 목표 역할

## 5. 상점 (잡화점)

| 품목 | 가격 | 비고 |
|---|---|---|
| HP 물약 | 15 | 효과는 balance.md |
| MP 물약 | 10 | |
| 기본 장식 | 3장 표 | |
| 의상 (모자·상의·하의·망토) | 150~400 | 외형 전용, 매주 일부 품목 교체 (MVP 이후) |
| 무기 외형 색 변형 | 200~500 | 기본·제작 외형의 색만 바꾼 버전, 매주 일부 품목 교체 (MVP 이후) |

- 개인 지갑으로 구매. 물약은 개인 인벤토리, 던전 입장 시 한도까지 자동 지참
- 의상 획득처: 잡화점 구매, 각 층 보스 첫 처치 시 그 층 테마 의상 1벌 (외형은 art.md)

### 무기 외형 (외형 전용, 능력치 없음)
| 경로 | 내용 |
|---|---|
| 대장간 제작 (주된 경로) | 층마다 그 층 테마로 무기 4종 외형 1개씩. 비용 = 층 재료 + 코인 (개인 지갑). 대장간 건설 후 이용 |
| 보스 희귀 드롭 (자랑거리) | 층마다 보스 전용 외형 1개. 보스 처치 시 개인별 5% 판정, **내가 쓰던 무기 종류**로 드롭. 그 보스를 20번 잡도록 안 나오면 다음 처치에 확정(천장). 휘두를 때 스미어 색이 다름 |
| 잡화점 색 변형 | 기본·제작 외형의 색만 바꾼 버전 (가격은 위 표) |

- 무기 종류마다 따로 장착 (대검 외형을 바꿔도 스태프는 그대로). 장착은 무기 거치대에서
- 거래·되팔기 없음
- 제작 비용(1층 기준 초안): 버섯 10 + 300코인. 층마다 재료·코인 ×1.5

## 6. 입장 흐름

1. 우물에 상호작용 → 층 선택 (해금된 층만)
2. **출발 대기**: 우물 주변에 대기 표시. 다른 주민이 우물에 상호작용하면 합류
3. 대기 시작자가 "출발" → 10초 카운트다운 (그 사이 합류 가능, 최대 4명)
4. 솔로는 "출발" 즉시 입장
5. DungeonRoom 생성 → 파티 전원 이동. 섬에는 접속 중 표시만 남음
6. 던전 종료 → 정산 화면 (코인, 재료, 경험치, 금고 적립, 콤보 보너스) → 섬 우물 앞으로 복귀

- 던전 중인 주민은 섬 화면에서 "탐험 중 (2층)" 같은 상태 표시
- 정산 결과는 게시판 기록으로 남음

---

## 7. 섬 주민

- 섬 하나당 주민 최대 4명 (파티 최대 인원과 동일). 1인 1섬
- 초대 코드로 합류. 초대 코드는 주민 누구나 새로 발급할 수 있고(이전 코드는 즉시 무효), 활동 기록에 남는다 (코드 생성·시도 제한은 docs/security.md)
- 섬을 떠나면: 본인이 개인 지갑으로 산 장식은 본인 인벤토리로 회수, 공용 장식·건물·트로피는 섬에 남음
- 마지막 주민이 떠나면 섬 데이터는 30일 보관 후 삭제

## 8. 활동 기록 (게시판)
- 장식 놓기·옮기기·치우기, 건물 건설, 연마, 금고 사용, 던전 결과, 보스 첫 처치
- 최근 100건 표시. 메모는 주민이 자유롭게 1줄 작성 (최근 20개)
