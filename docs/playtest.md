# 플레이 테스트 (docs/playtest.md)

사람이 직접 한 판을 해 보고 기록하는 체크리스트. 자동으로 볼 수 있는 것(규칙이 끝까지 도는지, 대략의 시간·보상)은 `pnpm run-sim`(balance.md 10장)이 맡고, 여기서는 **손맛·난이도·시간 체감**을 본다. 결과는 아래 기록 양식으로 남기고 다음 튜닝(balance.md 9장)에 반영한다.

---

## 1. 준비

- `pnpm dev` (클라이언트 + 서버)
- 솔로: `http://localhost:5173/?online=1&party=1`
- 2인: 탭(또는 기기) 2개에서 `http://localhost:5173/?online=1&party=2&lag=100&jitter=20` (지연 100ms·흔들림 ±20ms, M2 확인 기준)
- 조작: 방향키/WASD 이동(좌우 두 번 = 달리기) · J 평타(달리면 대시) · K 회피(방향키 쪽, 없으면 뒤) · U 올려베기 · I 대지가르기 · Z/X 물약 · E 상호작용
- 테스트 계정 `ADMIN` (개발 서버만, 닉네임 대소문자 무시·정확히 같을 때만): 섬에 들어올 때마다 대검·스태프 숙련도 Lv20(SP 19)·지갑 99,999로 다시 채움. 다른 닉네임은 환경 변수 TEST_ACCOUNT, 배포(production)에서는 꺼짐 (server/src/db/testAccount.ts, config.ts testAccount). 레벨·지갑을 보는 테스트(정산·레벨업)는 다른 계정으로
- 개발 패널 (\` 키): 지연 조정, 방 몬스터 모두 기절, 나 쓰러지기, 연결 끊기 — 테스트 기록에는 쓰지 않은 판만

## 2. 볼 것

| # | 항목 | 기준 |
|---|---|---|
| 1 | 한 판 시간 (1번 방 → 보스 클리어) | 목표 11~13분 (CLAUDE.md "한 판 10~15분", dungeon.md 5장) |
| 2 | 방마다 걸린 시간·막힌 곳 | 방 1~2분 (웨이브 1개 방 40~80초), 보스 2~3분 (balance.md 5장) |
| 3 | 조작감 | balance.md 9장 튜닝 항목: 평타 연타 리듬, 회피 무적 시간·지구력(회피 횟수·달리기 시간), 달리기 두 번 누르기, 경직·다운 길이 |
| 4 | 13px 라인 판정 (2인, 지연 100ms) | 화면에서 깊이를 맞췄을 때 맞고, 피했을 때 안 맞는 것이 체감상 공정한가 (network.md 13장, M2 남은 확인) |
| 5 | 몬스터 예고 | 멧돼지 돌진·버섯 박치기·포자탄·기사 내려찍기·이끼곰 패턴을 보고 피할 수 있는가 |
| 6 | 보스 | 구르기 → 벽 → 졸음 유도가 되는가, 졸음 연장(솔로 15히트·파티 2명)이 체감되는가 |
| 7 | 자원 | 물약 5개로 한 판이 빠듯한가 / 남는가, MP가 스킬 쓰기에 충분한가 |
| 8 | 협동 (2인) | 부활(E 2초), 팀 콤보, 출구 모이기, 귀환 지점이 자연스러운가 |
| 9 | 화면·소리 | 정산 화면, 보스 HP 바, BGM 전환, 효과음이 거슬리지 않는가 |

## 3. 기록 양식

```
날짜 / 인원 / 지연:
결과 (클리어·귀환·전멸) / 한 판 시간:
방별 시간: 1 __ 2 __ 3 __ 4 __ 5 __ 보스 __
쓰러짐 / 물약 사용 / 코인 / 레벨:
막힌 곳·버그:
조작감 (좋음·보통·답답함 + 한 줄):
라인 판정 체감 (공정·가끔 억울·자주 억울):
난이도 (쉬움·적당·어려움, 방별로):
바꾸고 싶은 것:
```

## 4. 자동 확인 결과 (run-sim, 2026-10 M3)

### 웨이브 증가 뒤 (A안)
| 조건 | 결과 |
|---|---|
| 2인 무적 봇 3판 | 3/3 클리어, 한 판 약 6분 40초 (방 32~73초, 보스 약 2분), 코인 약 365 · 경험치 288 |
| 솔로 무적 봇 3판 | 3/3 클리어, 방 34~102초, 보스 약 3분 20초. 4번 방은 봇 막힘(멧돼지) → 한 판 약 8~9분 추정 |

### 웨이브 증가 전

봇은 사람보다 단순하다 (덜 피하고, 멧돼지 돌진 거리 두기에 약함). 아래는 참고값이고 판단은 위 사람 기록으로 한다.

| 조건 | 결과 |
|---|---|
| 2인 무적 봇 3판 | 3/3 보스까지 클리어, 한 판 약 4분 40초 (방 15~70초, 보스 약 2분), 코인 약 375 · 경험치 312 |
| 솔로 무적 봇 3판 | 3/3 클리어. 3·5번 방은 봇이 멧돼지에 막혀(5분 넘음) 시간에서 뺌. 보스 약 3분 |
| 무적 아닌 봇 | 솔로·2인 모두 중간에 전멸 (봇이 피하지 못해 물약을 일찍 다 씀) — 난이도 판단 근거로는 약함 |

- 규칙(방 진행·보상·귀환·보스·정산)은 끝까지 막힘없이 돈다
- 코인·경험치는 balance.md 7장 목표(약 350, 약 300)에 맞음
- **한 판 시간은 목표(11~13분)보다 크게 짧다** (봇 2인 약 5분). ttk-sim(balance.md 5장)과 같은 결론 → 튜닝 결정 필요 (roadmap 3-9 보고)
