카드 24×34 (승인)

카드 24×29 → 24×34. 몸통 = 위 아이콘 창 + 아래 9줄 티어 띠 (띠 색 = 티어 색, 가운데 3×5 도트 숫자). 강화 = 숫자 뒤 "+" 하나 (별·금빛·금 모서리 없음). 없는 카드는 띠가 그림자, 숫자 없음.

계열 테두리 5종

줄마다: 티어 1 / 티어 1 강화 / 티어 2 / 티어 3 강화 / 없는 카드. 4배.

티어 1~10 띠 색

윗줄 일반, 아랫줄 강화. 3배. (지금 데이터는 티어 3까지)

카드 창 목록 배치

줄 간격 35 → 40. 장착 꼬리표(A S D), 고른 카드 꺾쇠, 강화 가능 ▲(깜빡임), 자물쇠(숙련도 모자람). 3배.

큰 카드 48×68 (카드 상점 고른 카드 · 팩 열기)

48×64 → 48×68 (작은 카드 테두리 24×34를 2배). 아이콘 칸 34×34(아이콘 2배) → 이름 → 아래 13줄 티어 띠(숫자 2배). 반짝임 없음, 강화 = 띠 숫자 뒤 "+" (이름 뒤 금색 + 그대로). 이름 글자는 데모라 브라우저 글꼴 (게임은 갈무리7). 3배.

장착 칸 22×22 (카드 창 위 줄)

강화 = 별 대신 오른쪽 아래 작은 "+" 판. 왼쪽 아래는 키 꼬리표. 왼쪽부터 일반 / 강화 / 강화 / 일반. 4배.
