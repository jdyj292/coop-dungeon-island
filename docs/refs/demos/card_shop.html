카드 상점 화면 (섬 카드 상점 앞 E) · 팩 열기 연출 (확정)

캔버스를 한 번 클릭하면 키보드가 먹어요. 아래 줄은 데모용 (게임에는 없음).

테두리 색 다음 팩 결과 (데모) 숙련도 (데모)
화면: 패널이 아닌 전용 화면. 위 = 카드 상점 그림과 같은 보라·크림 천막 띠 + 제목 · 카드팩 / 지정 구매 탭 · 코인 · 조각. 아래 = 나무 탁자, 왼쪽 판(무기·팩 고르기) + 오른쪽 어두운 펠트 매트(팩·카드가 놓이는 곳).
카드팩: 무기 → 팩 번호(열리지 않은 팩은 자물쇠 + Lv) → 매트에 고른 팩이 떠 있음, 확률·마지막 장·천장 안내 → 선물 팩 열기(환영 선물이 있으면 먼저) / 코인 / 조각 버튼. 산 팩은 바로 엽니다.
팩 열기: ① 팩이 떨어져 튕김 → 클릭·Enter ② 흔들리다(점점 세게, 하얗게) 윗부분이 찢겨 날아감 + 종이 조각 ③ 카드 4장이 뒷면으로 펼쳐짐 ④ 마우스를 올리거나 ←→로 고르면 뒷면이 티어 색으로 빛남 (티어 1 = 테두리 한 줄, 2 = 번짐 + 반짝이 2개, 3 = 크게 맥박 + 반짝이 4개) ⑤ 클릭·Enter로 한 장씩, A·"모두 뒤집기"로 차례로. 티어 1 = 짧은 뒤집기 + 먼지, 티어 2 = 섬광 + 반짝이, 티어 3 = 잠깐 멈춤(떨림·화면 어두워짐·빛 오름) → 빛기둥 + 화면 흔들림 + 이름 크게. 처음 얻은 카드는 NEW.
음악 (CD-6에서 소리): 매트 오른쪽 위 글자가 지금 곡 상태 — 잔잔 → 티어 2 빛을 보면 악기 한 겹 → 티어 3 빛을 보면 조 바뀜·웅장 → 다 뒤집으면 원래 곡으로.
합치기: 다 뒤집은 뒤 3장이 된 카드가 있으면 세 장이 가운데로 모여 하얗게 녹고 → 금테 강화 카드가 튀어나옴 → 변형이 있는 액티브면 바로 변형 고르기(나중에 = 기본 동작, 카드 창에서 다시 고름).
지정 구매: 무기·액티브/패시브 → 매트에 카드 목록(줄 = 기본/A/B, 카드 아래 = 조각 가격, 강화를 마친 카드는 흐림) → 왼쪽 판에 고른 카드 크게 + 조각 버튼. 사면 뒤집히며 티어 효과, 3장이 되면 같은 합치기 연출.
카드 앞면 48×64: 티어 테두리(강화 = 금테 + 안쪽 티어 색 + 흰 모서리) · 별 = 티어 · 아이콘 16×16 2배 · 계열 띠(A·B 계열 색, 기본은 어두움) · 이름. 패시브는 오른쪽 위 P. 뒷면: 어두운 격자 + 팩 색 마름모.

카드 테두리 비교 (티어 1 · 2 · 3 기본 / 강화)

A = 예전 임시값 (연보라 · 하늘 · 금). B = 확정 (은 · 파랑 · 보라, palette.json global.ui.card) — 금색은 강화 전용이라 티어 3과 강화가 헷갈리지 않음. 위 라디오로 게임 화면에도 적용돼요.
