# 스킬트리 (docs/skills.md)

무기 고유 특성·평타·스킬·스킬트리의 기준 문서. 플래그 의미는 docs/combat.md, 공식·예산은 docs/balance.md.
계수는 ATK 대비 %. 실제 값은 shared/data/skills.json.

---

## 1. 시스템

### 성장
- 무기마다 숙련도 Lv 1~20. 레벨업마다 SP 1 (Lv20까지 19), 각 층 보스 첫 처치 시 SP +1 (5층까지 5)
- 경험치 곡선은 balance.md
- 숙련도와 SP는 무기별로 따로

### 세 번의 선택
1. **단계마다 택1**: 각 계열의 각 단계에는 액티브 2개, 보조(패시브 또는 강화) 2개가 있고 각각 하나씩만 배울 수 있다
2. **변형 택1**: 액티브에 3포인트를 찍으면 변형 2개 중 하나를 고른다 (스킬 동작이 바뀜)
3. **슬롯 장착**: 배운 액티브 중 4개만 슬롯(U/I/O/P)에 장착

### 트리 구조 (모든 무기 공통)
```
[공용 기본] 액티브 2개 (처음부터 1포인트, 최대 3)
      │
  ┌───┴────────────────┐
[A 계열]              [B 계열]
1단계: 액티브 택1 / 보조 택1     (해금: 처음부터)
2단계: 액티브 택1 / 보조 택1     (해금: 같은 계열 3포인트)
3단계: 액티브 택1 / 보조 택1     (해금: 같은 계열 7포인트)
각성: 필살기                      (해금: 같은 계열 11포인트)
```
- 액티브 노드 1~3포인트, 보조 노드 1포인트, 각성 1포인트
- 한 계열 완성 = 13포인트, 기본 스킬 2개 최대 = +4포인트 → 17포인트
- 공용 패시브 최대 4포인트
- 최대 24포인트 (19 + 5) → 한 계열 완성(17) + 공용 패시브(4) + 여유 3, 또는 공용 패시브 대신 다른 계열 일부
- 같은 단계 택1 변경, 변형 변경, 전체 초기화 모두 섬에서 무료
- 필살기는 A형/B형 중 하나만 장착

### 공용 패시브 (모든 무기, 무기별 SP 사용)
| 이름 | 포인트 | 효과 |
|---|---|---|
| 스킬 캔슬 | 1~3 | 스킬 → 스킬 캔슬 가능. 캔슬된 다음 스킬 windup ×1.5 / ×1.3 / ×1.15 |
| 기상 회피 | 1 | 다운 후 기상 즉시 백스텝 가능 |

- 이 둘에 최대 4포인트 → 계열 투자와 경쟁 (구 던파식 "캔슬을 배울 것인가" 고민)

### 대시 공격 (모든 무기 공통 규칙)
- 달리는 중 J: 전진하며 공격 (거리는 무기별, 기본 2타일), knockback, 계수 = 해당 무기 평타 마지막 타 계수 × 1.2
- 무기별 판정·포즈는 shared/data/weapons.json

### 표 읽는 법
`| 단계 | 이름 | 쿨 | 계수 | 효과 | 변형 ① / ② |`
보조 노드는 쿨·계수·변형 없음.
**쿨은 기준 쿨** (실제 = × 1.5, balance.md). MP 소모 = 기준 쿨 × 2.
"팀 전체·동료" 대상 효과는 자기 자신도 포함 (솔로에서도 유효).

## 6. 계열별 팀 역할

| 무기 | A 계열 | B 계열 |
|---|---|---|
| 대검 | 파쇄: 광역 다운·한 방 | 검기: 원거리 연계·공중 딜 |
| 스태프 | 원소: 범위 딜·지형 | 중력: 체공·모으기·보호막 |
| 주먹 | 격투: 근접 연타 딜 | 철벽: 탱커·도발·보호 |
| 쌍검 | 질풍: 기동·공중 추격 | 암기: 표식·덫·팀 딜 증폭 |

- 모든 계열은 팀 콤보 고리(launch / hold / pull / down) 최소 1개
- 모든 계열은 동료에게 이득이 되는 노드 최소 1개
