# 스킬 (docs/skills.md)

무기 고유 특성·평타·스킬·스킬 카드 규칙의 기준 문서. 플래그 의미는 docs/combat.md, 공식·예산은 docs/balance.md.
계수는 ATK 대비 %. 실제 값은 shared/data/skills.json.

---

## 1. 시스템 — 스킬 카드 (CD, 2026-11)

스킬은 **카드**로 얻고 장착한다. SK-1~SK-7의 SP·레벨 열림·계열 선택 규칙은 CD에서 이 규칙으로 바뀜 (옛 규칙은 git 기록, 승인 데모 docs/refs/demos/skill_window.html은 지난 기록). 가격·확률·조각 값은 balance.md 7장 카드 경제, 카드 상점은 island.md 2·5장, 카드 창은 hud.md 8장.

### 카드
- 스킬 하나 = 카드 하나. 액티브(기본 스킬·계열 액티브)도, 패시브(계열 보조·공용 패시브)도 카드. 카드는 무기마다 따로 (대검 카드는 대검에만)
- 공용 패시브(기상 회피)는 무기마다 카드 하나씩 (`<무기>.quickrise`), 계열 없음
- 카드마다 숫자 **티어** (1이 가장 낮음, 확장은 숫자만 늘림). 티어별 값(장착 숙련도·조각·지정 구매 가격·테두리 색)은 cards.json `tiers` 한 곳 (data.md 10장). 화면에는 테두리 색 + 별 개수
- 지금 티어 (옛 열림 레벨을 그대로 옮김):

| 티어 | 장착 숙련도 | 카드 |
|---|---|---|
| 1 | Lv1 | 기본 스킬 2개, 계열 액티브 Lv2·4, 계열 보조 Lv3·5, 공용 기상 회피 |
| 2 | Lv6 | 계열 액티브 Lv6·8, 계열 보조 Lv7·9 |
| 3 | Lv11 | 계열 3단계 액티브 Lv11·13, 보조 Lv12·14 |
| 4~ | — | 비워 둠 (각성 등) |

- 아래 2~5장 표의 "Lv" 열은 옛 열림 레벨. 그 줄의 카드 티어는 위 표로 읽는다 (cards.json이 기준)

### 얻기
- **카드팩** (카드 상점, island.md 5장): 무기별·팩 번호별. 팩 번호가 클수록 높은 티어가 나옴 (팩 1 = 티어 1~2, 팩 2 = 티어 1~3). 한 팩 4장. 같은 티어 안에서는 그 무기 카드가 같은 확률. 굴림은 서버
- **처음 카드**: 계정마다 무기별 기본 스킬 카드 2장을 1장씩 (예: 대검 올려베기·대지가르기). 팩에서도 나옴 (강화용)
- **갈기**: 카드 1장 → 카드 조각 (티어별 값). 조각은 모든 무기가 함께 쓴다 (users.dust)
- **조각으로**: 카드팩 사기, 또는 카드를 골라 1장 사기(지정 구매, 티어별 가격)

### 강화 (3장 → 강화 카드)
- 같은 카드를 3장 모으면 저절로 합쳐져 **강화 카드**가 된다 (3장 소모, 팩 열기 끝에 합치기 연출). 단계는 기본·강화 둘뿐
- 강화 액티브: 위력 ×1.2 (combat.json card.enhancedMul, 계수에 곱함 = 후속·반복·해제 판정 포함) + **변형 택1** (스킬 표의 변형 ① / ②, 안 고르면 기본 동작). 변형은 섬에서 언제든 무료로 다시 고름
- 강화 패시브: 효과가 강화 값으로 (passives.json 값 배열 = [기본, 강화], 옛 1포인트 값 → 기본, 3포인트 값 → 강화)
- 강화한 뒤 다시 나오는 같은 카드는 보관만 됨 (쓰임 없음 → 카드 창에 "갈기 추천")

### 장착
- 무기마다 따로 저장 (DB card_slots). 던전 출발 때 서버가 장착 카드만 담은 빌드를 만들어 판정 (클라이언트 신고값 신뢰 금지)
- **액티브 4칸** (A S D F): 기본 스킬 카드도 이 4칸에 넣는다. 장착 안 한 액티브는 던전에서 못 씀. 처음 배치 = A S에 기본 스킬 2장
- **패시브 칸** = 비용 합계 한도. 카드 비용 = 티어 (cards.json `cost`, 없으면 티어), 강화하면 +1. 한도는 숙련도 Lv1에 2, 2레벨마다 +1 (Lv3 3 … Lv19 11, combat.json card.passiveCap). 같은 카드는 한 번만
- **장착 숙련도**: 카드 티어의 장착 숙련도보다 그 무기 숙련도가 낮으면 장착 불가 (지정 구매로 높은 티어를 먼저 얻어도 마찬가지)
- **계열 섞기**: 계열 선택은 없앰. 파쇄·검기 카드를 섞어 끼울 수 있다

### 계열 보너스
- 장착한 같은 계열 카드(액티브 + 패시브) 수로 켜짐. 기본 스킬·공용 패시브는 세지 않음
- 3장 = 보너스 Ⅰ, 5장 = 보너스 Ⅱ (Ⅱ가 Ⅰ을 대신). 크기는 작게 (Ⅱ도 체감 10~15%): 몰아 끼우기와 섞기가 둘 다 쓸 만하게
- 계열다운 효과로 (피해 % 금지). 값은 cards.json `branchBonus` (CD-7에서 조정):

| 무기 | 계열 | Ⅰ (3장) | Ⅱ (5장) |
|---|---|---|---|
| 대검 | A 파쇄 | 충전 속도 +15% | 충전 속도 +25%, 충전 최대 보너스 +10%p |
| 대검 | B 검기 | 투사체 사거리 +15% | 투사체 사거리 +25%, 투사체 스킬 쿨 −10% |
| 스태프 | A 원소 | 원·장판 판정 크기 +10% | 크기 +15%, 스킬 MP −10% |
| 스태프 | B 중력 | 감속 시간 +20% | 감속 시간 +30%, 감속량 +5%p |

### 숙련도
- 무기마다 Lv 1~20 (경험치 곡선 balance.md). 숙련도가 정하는 것: 최대 HP·ATK, 패시브 칸 한도, 열리는 카드팩, 장착할 수 있는 티어
- SP는 없음 (CD에서 없앰). 보스 첫 처치 보상은 MVP 이후 다시 정함 (카드팩 등)

### 기록 초기화 (CD-3)
- 옛 스킬 기록(skill_nodes·skill_slots·weapon_mastery.sp·branch)은 지움. 숙련도 레벨·경험치는 그대로
- 모든 계정에 무기별 처음 카드 2장 + 환영 선물 팩 1 3개(무기 아무거나 열 수 있음, balance.md 7장 카드 경제)

### 개발
- `?skills=gs_whirl:2:rush,gs_heavyhand:1` (로컬 던전 빌드, 보유·티어·숙련도 검사 없음). `id:1` = 기본, `id:2` = 강화, 셋째 = 변형(강화일 때만). 장착 순서대로 액티브 A S D F, 패시브는 한도 검사 없음
- 테스트 계정 ADMIN은 조각도 채움 (playtest.md 1장)

### 트리 구조 → 카드 목록 (모든 무기 공통)
```
[기본 스킬] 액티브 2장 (티어 1, 처음부터 1장씩)
[공용 패시브] 기상 회피 (티어 1)
[A 계열] [B 계열] (둘 다 카드로, 섞어 장착)
  티어 1: 액티브 2 · 보조 2   티어 2: 액티브 2 · 보조 2   티어 3: 액티브 2 · 보조 2 (대검 A·B 계열부터)
  (각성·아직 안 만든 계열의 3단계 = MVP 이후, 티어 4 후보)
```
- 필살기는 A형/B형 중 하나만 장착 (MVP 이후)

### 공용 패시브 (모든 무기, 무기별 카드)
| 이름 | 티어 | 효과 (기본 / 강화) |
|---|---|---|
| 기상 회피 | 1 | 다운 중 회피 키로 바로 일어나며 회피 / 그 회피 쿨 −0.2초 |

- 스킬 캔슬(스킬 → 스킬, SK-5)은 2026-11 없앰: 스킬은 끝까지 쓴다 (combat.md 캔슬 규칙). 그림 cancel은 남김
- 기상 회피 (SK-5): 다운 중 밀림(player.json hurt pushSec)이 끝난 뒤 회피 키 → 다운을 끝내고 바로 회피. 기상 무적(getupInvuln 1초)은 없고 회피 무적이 대신, 회피 쿨·지구력은 평소대로 (player.ts canQuickRise, 서버 inputs.ts도 다운 중 이 회피만 받음). 강화 = 이 회피의 쿨에 effect.quickRiseCooldownAdd

### 대시 공격 (모든 무기 공통 규칙)
- 달리는 중 J: 전진하며 공격 (거리는 무기별, 기본 2타일), knockback, 계수 = 해당 무기 평타 마지막 타 계수 × 1.2
- 무기별 판정·포즈는 shared/data/weapons.json. 대검 대시 후딜레이(recovery)는 0.55초 (2026-10 0.35에서 늘림: 대시 남발 억제)
- 대검 평타 1~3타는 바라보는 방향 키를 누르고 있으면 초당 20px 전진, 각 타 끝 0.15초 전부터는 멈춤 (weapons.json basicAdvance speed·stopBefore, 1타 0.58초 → 약 9px)

### 표 읽는 법
`| Lv | 이름 | 쿨 | 계수 | 효과 | 변형 ① / ② |` (Lv = 옛 열림 레벨 → 카드 티어는 1장 표, 변형은 강화 카드에서 고름)
보조 노드(패시브 카드)는 쿨·계수·변형 없음. 표의 보조 효과는 기본 카드 값, 강화 값은 passives.json pointDesc (예: 무거운 손 충전 +30% → 강화 +60%·피해 −30% → −50%, 굳건함 강화 = 스킬 중 받는 피해 −20%).
Lv 열이 "3단계"·"각성"인 줄은 아직 없는 카드 (3단계 = 티어 3, 대검 A·B 계열은 SK-7에서 만듦). 4·5장 주먹·쌍검 표의 단계 열은 옛 구조, 구현 때 티어로 바꾼다.
**쿨은 기준 쿨** (실제 = × 1.5, balance.md). MP 소모 = 기준 쿨 × 2.
"팀 전체·동료" 대상 효과는 자기 자신도 포함 (솔로에서도 유효).

## 2. 대검
고유: 충전(홀드 최대 1초, 데미지·범위 최대 +50%, 충전 중 슈퍼아머) / 이동 ×0.9
- 충전 규칙 (shared/src/charge.ts, weapons.json trait): 대검 스킬(A S D F G H) 키를 누르고 있으면 준비(windup) 끝에서 멈춰 충전, 떼면 발동. 최대(maxTime 1초)까지 차도 바로 나가지 않고 계속 들고 있을 수 있으며(보너스는 최대 그대로, 슈퍼아머 유지), 다 찬 뒤 holdMax(2초)가 지나면 저절로 발동. 준비 안에 떼면 충전 없이 지금처럼 바로
- 보너스 = bonusMax(0.5) × 충전 시간 / 최대 시간: 계수(후속·벽꿍·해제 판정 포함) × (1 + 보너스), 범위는 상자 길이(width·back)·깊이, 원·부채꼴·사각 장판 크기, 투사체 반지름 × (1 + 보너스). 상자 시작 위치(forward)·투사체 사거리는 그대로
- 연출 (SK-3 2차): 충전 포즈(skills.json poses.charge, 허리 옆 쥐기·머리 위 스킬은 그대로)·모이는 빛·효과음 charge_start/charge_full, 충전 중 모이는 소리 charge_gather·다 찰 때 charge_ready와 큰 별·빛살·몸 둘레 고리, 다 찬 채 들고 있으면 손 둘레 반짝이 (art.md 4·7장, audio.md 3장)
- 충전 중(준비 끝에서 멈춘 동안)만 슈퍼아머, 이동 불가. 쿨타임·MP는 지금처럼 스킬을 시작할 때. 평타·대시 공격, 재입력 변형의 다음 입력은 충전 없음
평타: 200 / 200 / 350% (3타 launch + inplace: 밀지 않고 제자리에서 위로만 띄움, 띄우는 힘은 기본 launchVz). 평타 콤보 중 방향 전환 불가 (basicTurn false)
