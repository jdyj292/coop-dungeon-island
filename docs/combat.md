# 전투 규칙 (docs/combat.md)

구 던전앤파이터식 벨트스크롤 전투를 2D 도트로 구현한 구조.
좌우로만 공격하고 위아래(깊이)로 이동하며, 몬스터는 높이(z)로 띄워 공중 콤보가 가능하다.

**조작감 원칙: 묵직하고 약간 답답하게 (의도된 제약)**
- 아무 때나 피하거나 끊을 수 없다. 한 번 휘두르면 책임진다
- 라인(깊이)을 맞춰야 맞는다
- 자원(MP·물약)이 빠듯해 평타 비중이 높다
- 플레이어도 맞으면 경직되고 다운된다
- 이 불편함을 동료(도발, 묶기, 보호)가 덜어주는 것이 협동의 가치

문서 역할: 이 문서 = 전투 동작 규칙 / docs/skills.md = 무기·스킬 / docs/balance.md = 모든 수치
좌표·단위는 CLAUDE.md "좌표 규칙".

## 1. 이동과 조작

### 조작
| 키 | 행동 |
|---|---|
| WASD / 방향키 | 걷기. 좌우 입력 시 바라보는 방향 변경 (공격 중 불가) |
| 좌우(A/D 또는 ←/→) 빠르게 두 번 | 달리기 (좌우 입력을 떼면 해제) |
| J | 평타. 달리는 중이면 대시 공격 (무기별, skills.md) |
| U / I / O / P | 스킬 슬롯 1~4 |
| L | 필살기 (게이지 100) |
| K | 백스텝 |
| Z / X | HP 물약 / MP 물약 |
| E | 상호작용 (부활, 줍기) |
| 1~4 | 이모트 |
| Enter | 채팅 입력 (입력 중에는 캐릭터 조작 정지, 규칙은 docs/hud.md 4장) |

### 이동 속도 (데이터: shared/data/player.json)
| 상태 | 좌우 | 깊이(위아래) |
|---|---|---|
| 걷기 | 60px/s | 40px/s |
| 달리기 | 120px/s | 75px/s |

- 깊이 이동이 느린 것이 핵심: 라인 맞추기 자체가 긴장 요소
- 무기별 배율은 skills.md

### 백스텝 (모든 무기 공통, 회피 수단은 이것뿐)
- 바라보는 반대 방향으로 2.5타일 뛰어 물러남, 0.25초, 그중 앞 0.2초 무적
- 쿨타임 2초. 공격 중(어느 구간이든) 사용 불가
- 스태프는 같은 성능의 짧은 순간이동 (연출만 다름)

### 공격 중 제약
- 공격·스킬 중 이동 불가 (스킬 자체 이동 제외)
- 방향 전환은 평타 단계 사이(recovery 진입 직후 0.1초)에만 가능
- 스킬은 시작하면 끝까지 진행 (캔슬 규칙 참고)

## 2. 판정과 행동

### 공격 판정
- 사각형 판정: 바라보는 방향 기준 앞쪽 offset + 너비 + 깊이 + 높이 조건
- **깊이 폭은 좁게 (기본 13px)**. 라인을 정확히 맞춰야 적중
- 광역 스킬만 깊이 폭을 넓게 (스킬 데이터에 명시)
- 높이 조건: `ground` / `air` / `both`
- 모든 데미지·명중 판정은 서버

### 행동 구조
- windup(선딜) → active(판정) → recovery(후딜)
- 각 행동은 세 구간 길이 + 판정 + 플래그 + 이펙트를 데이터로 정의

### 속성 플래그
| 플래그 | 효과 |
|---|---|
| launch | 대상을 띄움 (vz 부여) |
| knockback | 바라보는 방향으로 밀어냄. 벽에 닿으면 벽꿍 |
| down | 공중 대상을 내리꽂음 → 바운드 없이 바로 다운 |
| downhit | 다운 상태 대상도 적중. 맞은 대상은 바닥을 미끄러짐 |
| pull | 공격자 쪽으로 끌어옴 |
| hold | 공중 대상 체공 유지 |
| grab | 잡기 (슈퍼아머 대상 불가) |
| multi | 다단히트 |
| projectile | 투사체 |

### 캔슬 규칙 (기본은 엄격)
- 평타 recovery → 스킬: **가능** (기본)
- 스킬 → 스킬: **불가**. 공용 패시브 "스킬 캔슬"을 배워야 가능, 캔슬 시 다음 스킬 windup 증가 (skills.md)
- 어떤 행동 → 백스텝: 불가
- 필살기: 어떤 행동이든 캔슬하고 발동 (유일한 예외)

### 자원
- 스킬은 쿨타임 + MP 소모. 물약은 던전 반입 개수 제한 (수치는 balance.md, 가격은 island.md)

## 3. 몬스터 상태와 높이(z)

### 상태
idle → chase → attack(windup/active/recovery) → hitstun → airborne → bounce → down → getup → stunned(체력 0, 기절 후 퇴장)

### 높이(z)
- 몬스터마다 z, vz (서버 상태에 포함). 렌더링은 z 높이, 그림자는 바닥 고정
- 몬스터도 좌우로만 바라본다 (백어택 판정 기준: 몬스터가 바라보는 반대쪽에서 맞음)
- 중력 600px/s². launch 기본 vz 220 → 체공 약 0.7초
- 공중 피격 시 재부양 vz +60 (hold는 vz 0 유지)
- 플레이어는 z 없음 (항상 지상). **점프 없음 (확정)** — 뛰어오르는 모습은 스킬 연출(예: 승천검)로만, 판정은 지상

### 바운드
- 공중에서 자연 착지하면 한 번 튀어 오름 (vz 90, 약 0.3초). 바운드 중에도 피격 가능 (공중 판정)
- 바운드 후 착지 → 다운. down 플래그로 내리꽂으면 바운드 생략

### 벽꿍
- knockback으로 밀려난 대상이 벽에 닿으면 튕겨 나오며 추가 경직 0.3초
- 공중에서 벽에 닿으면 벽에서 미끄러져 내려온 뒤 바운드

### 공중 콤보 보정 (무한 콤보 방지)
- 공중 피격마다 대상 중력 ×1.1 누적
- 띄운 뒤 공중 피격 12회 초과 시 강제 down
- 착지(다운)하면 초기화

### 경직
| 공격 강도 | 경직 | 밀림 거리 |
|---|---|---|
| 약 | 0.3초 | 6px |
| 중 | 0.45초 | 12px |
| 강 | 0.6초 | 24px |

무게 보정 (경직·밀림 모두): light ×1.0 / medium ×0.8 / heavy ×0.5 / boss ×0
- fixed(포자꽃 등 고정형): 경직 ×1.0, 밀림 0, launch·knockback·grab 무시

### 다운
- 0.8초 다운. 다운 중에는 downhit만 적중 (데미지 보정은 balance.md)
- 기상 시 0.5초 무적

### 슈퍼아머
- 보스: 기본 슈퍼아머. 졸음(그로기) 상태에서만 해제
- 정예 몬스터: 자신의 공격 windup~active 동안 슈퍼아머 (맞으면서 때린다)
- 슈퍼아머 대상: 경직·밀림·띄우기·잡기 무시, 데미지만 받음

## 4. 플레이어 피격

- HP 바와 데미지 숫자 사용 (수치는 balance.md)
- 약 공격: 경직 0.2초 / 강 공격(몬스터 데이터에 표시): 다운 1.0초
- 다운 후 기상 시 1.0초 무적 (공용 패시브 "기상 회피"로 기상 즉시 백스텝 가능)
- 경직 중 연속 피격 가능. 포위당하면 위험하다는 것이 의도
- HP 0 → 쓰러짐. 동료가 E를 2초 누르면 HP 30%로 부활 (솔로는 부활의 깃털, dungeon.md)
- 전멸 처리는 CLAUDE.md 핵심 게임 규칙

## 5. 연출 등급

| 등급 | 히트스톱 | 화면 흔들림 | 기타 |
|---|---|---|---|
| 약 (평타) | 0.05초 | 없음 | 타격 섬광 파티클 |
| 중 (스킬) | 0.09초 | 약하게 | 피격 대상 흰색 번쩍임 |
| 강 (마무리 타격) | 0.13초 | 방향성 흔들림 | 먼지·충격파 링 |
| 필살 | 0.2초 + 0.3초 슬로우 | 강하게 | 발동 시 화면 정지 + 캐릭터 컷인 (확대 대신 정수 배율 유지) |

- 이 표는 시간 값(히트스톱·흔들림)의 기준. 번쩍임 프레임 수·섬광·숫자 등 타격 패키지 구성은 docs/motion.md 3장
- 타격음은 저음 강조 (docs/audio.md). 바운드·벽꿍·다운 미끄러짐에도 각각 짧은 효과음과 먼지
- 흔들림 방향: 내려찍기는 상하, 옆으로 날리는 기술은 좌우
- 내 행동은 입력 즉시 windup 애니메이션 재생
- 이펙트의 모양·색은 docs/art.md. 리듬·타격 패키지·피격 반응은 docs/motion.md. 피·잔혹 표현 없음

## 6. 몬스터 AI 공통

- 층별 몬스터·정예·보스 내용은 docs/dungeon.md
- 감지 거리 기본 5타일. 체력 0 → 기절 → 코인·재료 드롭 후 퇴장
- **공격 토큰**: 동시에 공격 동작에 들어갈 수 있는 몬스터 수 제한. 토큰 없는 몬스터는 거리를 두고 맴돌며 위치를 잡음 (토큰 수는 balance.md, 규칙은 dungeon.md)
- 모든 몬스터 공격은 예고(windup)가 보여야 한다. 강 공격은 예고를 더 길게

## 7. 협동

### 팀 콤보
- 서로 다른 플레이어의 적중이 1.5초 안에 이어지면 카운터 유지
- 20 / 40 / 60 달성 시 이번 판 코인 +5% / +10% / +15% (게이지 보너스는 balance.md)
- 솔로는 개인 콤보로 대체 (dungeon.md)

### 합동 필살기
- 2명 이상이 2초 안에 필살기 발동 시 연출 강화 + 데미지 +20% (피해 증가 합에 포함)

### 연계 예시
- 대검 올려베기 → 바운드 순간 스태프 화염 폭발 → 대검 대지가르기
- 주먹(철벽) 포효로 몰이 → 스태프 중력 우물 → 대검 회전베기
- 정예 몬스터 슈퍼아머 → 스태프 얼음 장판 빙결로 행동 봉쇄 → 대검 최대 충전

## 8. 구현 순서 (권장)
1. 걷기·달리기·백스텝, 공격 중 제약, 판정 + 대검 평타 + 히트스톱
2. 몬스터 상태 머신 + 경직·밀림 + 높이/중력 + 바운드·다운
3. 플레이어 피격(경직·다운·기상 무적) + HP·MP + 물약
4. 대검 기본 스킬 + 캔슬 규칙
5. 멀티플레이 동기화 후 팀 콤보
6. 스태프, 벽꿍, 정예 슈퍼아머, 공격 토큰, 보스
